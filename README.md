# Tidybun site

Static website for the Tidybun iPhone app (home, support, privacy, terms). No build step, no scripts.

- Pages: `index.html`, `support.html`, `privacy.html`, `terms.html`; one stylesheet `style.css`; icon `icon.svg`.
- `app-ads.txt` authorises Google AdMob. It must also be served from the root of the developer website domain (see `../tidybun-site-root/`).
- Support email: keytasupport@gmail.com (shared with Keyta). App Store button is a "Coming soon" placeholder in `index.html`; swap in the link at release.
- Light and dark mode follow the system setting. Preview by opening `index.html` in a browser.
